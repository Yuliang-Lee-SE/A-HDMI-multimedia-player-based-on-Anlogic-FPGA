# TF 复位修复候选（默认 32 张）

修复新 TF 控制与 SPI 字节机复位不同步：将复位保持到 TF 控制能采样后再同步释放。本地回归和标准构建通过；原 bit 黑屏的确切原因仍未证实，新候选待 A 上板。

使用 **`tf_fat32_32_reset_candidate.bit`**，SHA256：`1e4f31112784cdf1ee8f9d9f7d50876c1c798226ad06b4bac2fb2b8a959f397c`。先 [按逐步说明准备卡并做 RAM 测试](TESTING.md)，无需重新编译，不写 Flash。

需要 TF 卡（microSD）和读卡器：FAT32、512B 逻辑扇区、簇大小 512B～32KiB；首测根目录放 `0001.BMP`～`0004.BMP`，之后补齐到 `0032.BMP`。命名支持 `0001.BMP`～`9999.BMP`，本构建合计最多 32 张。BMP 必须 640×480、24 位、BI_RGB、正高度、40B DIB 头；JPG 改后缀不算转换。TF 卡不放 bit、镜像、字幕或音频。

原按键保持：KEY1复位，KEY2下一张，KEY3按1×→2×→0.5×循环，KEY4开关轮播。ID1～4有原字幕/ROM声音，其余无中文且静音；同图缩放不重启滚动/声音。失败保留旧图和声音，下一张可重试，锁定时KEY1复位。

A 首轮依次检查：首图/声音→4张切换→三档/快速切换→完整32张（4→5、31→32、回首）→轮播→缺号/坏BMP/恢复。连续/碎片要分别记录，普通复制不保证碎片；多卡、实卡速度、长时、RAM/Flash/掉电仍分别待验证。反馈附bit SHA、卡/簇信息、完整文件名、按键顺序、实际状态码和照片视频。

回退：[正常 P2](../osd_scroll_20261011/README.md)，配套 bit SHA256 `01e56c3f9c88cee49202390a09af25c4061757ef6d42760d6c2c11d325801e40`。保留原正常卡/镜像并恢复配套素材布局，旧裸扫描 bit 不保证读取新碎片卡。旧 TF 黑屏候选保留作历史，不作为正常回退。
