# SD初始化失败：诊断版

最新复位版 `1e4f3111` 已反馈初始化失败、F/黑屏/无声；旧bit仍能正常运行。本包增加具体失败读出，**没有宣称初始化已修复**。

使用 `tf_fat32_32_init_diagnostic.bit`，SHA256：`f7a7633b3957a05f0ef81a1c9dbbca347d5782a5ab834f66aee1e30ad49d79c3`。A沿用同一张已核对的TF卡，按[三步测试](TESTING.md)RAM加载后拍完整数码管；无需重新做卡、换图或重新编译，不写Flash。

失败时六位格式为 **`RCCBBF`**：原因1位、命令号2位（十六进制）、接收值2位、原F。成功时其余五位仍空白。请给实际完整照片，不只反馈F。

卡格式仍为FAT32/512B扇区/512B～32KiB簇/MBR主分区或直接卷；图片放根目录，四位数字`.BMP`命名，最多32张，640×480/24bit/BI_RGB/正高度/40B DIB头。bit不放进TF卡，图片格式无需为本诊断版改变。

原按键：KEY1复位、KEY2下一张/重试、KEY3三档缩放、KEY4轮播。首图提交前无图无声不另判HDMI/音频故障。若成功，ID1～4有原中文/ROM声音，其余静音；同图缩放不重启声音或滚动。

正常回退：[P2与配套旧卡布局](../osd_scroll_20261011/README.md)。两份失败FAT32 bit均保留为历史；旧裸扫描bit不保证读取新碎片布局。
