## 用卡与图片

FAT32；逻辑扇区512B，簇512B～32KiB；支持MBR主分区或直接卷。图片放根目录，以四位数字命名，如`0001.BMP`、`0002.BMP`，编号0001～9999、按编号排序、缺号可用；**本bit最多32张**。连续和碎片文件均设计支持。

每张为640×480、24位、未压缩BI_RGB BMP，40B DIB头、正高度（bottom-up）。将合规BMP复制进TF根目录，安全弹出后在板卡断电时插卡。现有已核对卡无需重新格式化；保留原正常卡/镜像。
