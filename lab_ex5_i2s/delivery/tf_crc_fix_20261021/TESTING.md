# 首图恢复后再做完整板测

先执行README三步；若仍失败，先返回完整码，不要求反复格式化或重做相同测试。

| 检查 | 操作与预期 |
| --- | --- |
| 32张/编号 | 用0001.BMP～0032.BMP逐张切换，重点4→5、31→32、32→1；缺号应跳过，编号与图片对应 |
| 缩放与忙时请求 | 每档检查完整画面；加载中按切图/缩放，完成后应显示最终请求且无半帧/混帧 |
| 轮播 | KEY4开/关，跨过第4和第31项，检查稳定切换 |
| 字幕/声音 | ID1～4检查既定映射，其他ID无中文且静音；同图缩放不重启滚动/声音 |
| 连续/碎片文件 | 各一组；碎片须有实际簇链证据，不能仅凭复制顺序声称碎片已测 |
| 坏BMP | 在测试卡副本放格式错误或截短文件；应报错、保持旧图/声音，不提交损坏帧 |
| 读卡恢复 | 故障测试须先保护正常卡/镜像；中途读失败不得提交半帧，恢复连接后KEY2重试或KEY1复位 |
| RAM/Flash/掉电 | 分别记录实际方式和结果；一次Flash运行不等于RAM、校验及多次掉电启动均通过 |

反馈：bit SHA256、下载方式、卡品牌/容量/格式、文件清单、完整数码管照片及出现时间，附失败前按键操作。实际卡速度、多卡兼容、长时运行和冷启动仍待持板者验证。本地仿真不替代这些项目。
