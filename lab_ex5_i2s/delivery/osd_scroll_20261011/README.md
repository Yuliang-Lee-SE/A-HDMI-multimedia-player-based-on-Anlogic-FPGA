# 滚动简介字幕

使用 `osd_scroll_candidate.bit`。标题固定，长简介向左滚动，短简介不动；切图从头开始，同图缩放继续滚动。按键操作沿用原版。

图片1、3使用加长测试简介，图片2、4保留短文。每2帧移动1像素，开头和末尾停约0.75秒。轮播仍为3秒一张，想看完整简介请关闭轮播、停留在当前图片。

本地像素、控制回归及综合布线通过，待上板。主要检查滚动是否流畅、边缘有无残影，切图与缩放时字幕是否对应，声音和波形是否正常。异常请拍画面并说明按键操作。

回退版在 `../osd_punctuation_20261011/`；之前已上板的静态版在 `../osd_three_zoom_20261011/`。
