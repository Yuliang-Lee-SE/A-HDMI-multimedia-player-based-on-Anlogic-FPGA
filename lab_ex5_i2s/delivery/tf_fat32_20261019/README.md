# TF卡多图片播放器：上板入口

**需要TF卡（microSD）和读卡器。** 图片从TF卡读取；字幕、声音仍是原来的固化资源，不需要往卡里放字幕或音频文件。先按下面的说明做RAM上板，不先写Flash。

**第一次测试请直接看：[一步一步的测试说明](TESTING.md)**。包含准备卡、生成图片、复制、加载bit、按键验收和故障排查。

| 项目 | 必须满足 |
| --- | --- |
| TF卡 | FAT32，512B逻辑扇区；普通MBR主分区或直接FAT32卷，不用exFAT/GPT |
| 图片位置 | 卡根目录，例如 `E:\0001.BMP`，不能放进子文件夹 |
| 文件名/数量 | `0001.BMP`～`9999.BMP`，按编号排序，允许缺号；本bit最多32张，首测只放4张也可以 |
| 图片格式 | **640×480、24位、无压缩BI_RGB的BMP，正高度bottom-up，40B信息头**；JPG/PNG改后缀不行，32位BMP/top-down也不支持 |
| 最省事的素材 | 使用仓库提供的Python脚本生成，命令见TESTING；只复制生成的BMP，不复制整个文件夹 |

使用本目录 `tf_fat32_32_candidate.bit`，SHA256：

`cb1948f2d151a5379022edbcdab7d62b2e1d61b906585656c7c27c5a75a95570`

原按键：KEY1(A2)复位；KEY2(B2)下一张；KEY3(B1)循环1×→2×→0.5×；KEY4(C1)开关轮播。

先查首图、切图、三档及声音，再查32张边界、轮播和坏文件。**ID1～4有原字幕/声音，其余图片无中文且静音是正常现象。** 加载中和失败时保留旧图/声音，同图缩放不重启滚动或音轨。

候选尚待A实板验证。实卡速度、多卡、长时、RAM/Flash/掉电结果分别记录；验证范围见 [RESULTS](RESULTS.md)，身份见 [manifest](manifest.json)。保留正常P2 bit和原正常卡/镜像，回退要恢复配套素材布局。
