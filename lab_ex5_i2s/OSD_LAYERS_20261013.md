# 半透明字幕面板与文字阴影

P3从已获“上板没问题”反馈的P2 `04c90d7`继续。默认深蓝面板保留25%的底图，状态/标题/简介加右下1像素黑影；滚动、三档缩放、切图、轮播、音频和波形沿用原版。当前按键不变，配置输入在顶层固定为默认值。

布局和延迟：面板592×76，默认左上角(24,380)。新图层共4级，替代原状态1级＋字幕3级；后级波形仍1级，总延迟不变。优先级为文字、黑影、边框、半透明面板、底图，最后由波形覆盖。阴影裁剪在各文字窗口内；双行1bit掩码交替读写不同RAM地址，避免器件同址读写模式依赖。首行/首列屏蔽未写历史，不复位或初始化RAM数组。

`team/osd_layer_renderer.v`提供同视频时钟域的配置接口。`cfg_valid && cfg_ready`接收整包，下一次VS结束消隐期一起生效；同沿新接收的请求延至再下一帧。ready表示可接收，不能视为已经显示。一次保存一包，忙时保持valid及数据直到ready。跨其他时钟域的调用者需另外接可靠CDC，不能逐位同步后直接使用。

| 字段 | 默认 | 有效范围与行为 |
| --- | --- | --- |
| cfg_show | 1 | 面板、状态、标题、简介一起开关；关闭期间滚动暂停，重新显示继续 |
| cfg_x / cfg_y | 24 / 380 | 限制到x=0..48、y=96..404，面板完整留在屏幕内并避开顶部波形 |
| cfg_alpha | 3 | 0..4，对应面板占0、1/4、1/2、3/4、全部；超限按4处理 |
| cfg_shadow | 1 | 黑色右下1像素阴影开关 |
| cfg_pause | 0 | 暂停时保留滚动、步进及停顿进度 |
| cfg_step | 2 | 1..8帧移动1像素，超限限制到边界；调整位置/样式不重启滚动 |

配置开关不影响声音和波形。新展品仍从头滚动，同图缩放继续；隐藏时切换展品会记住新ID、从该展品开头恢复。轮播仍3秒一张，查看完整长简介请使用手动模式。
