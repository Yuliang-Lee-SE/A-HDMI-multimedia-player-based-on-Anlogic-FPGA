# 仓库结构与基线说明

> 更新日期：2026-10-05
> 适用赛题：全国大学生嵌入式芯片与系统设计竞赛 · 安路赛道 · 选题一
> 硬件平台：HX4S20C（EG4S20BG256）

## 1. 目录结构

| 路径 | 用途 | 维护人 |
| --- | --- | --- |
| `lab_ex5_i2s/` | 官方 lab_ex5 例程基线（完整 TD 工程，编译与下板以此为准） | A |
| `lab_ex5_i2s/src/td_project/HDMI1.4b_Transmitter_v1.0.al` | TD 工程文件，用 TD 直接打开 | A |
| `lab_ex5_i2s/src/user_source/hdl_source/` | RTL 唯一权威源码，所有修改在这里进行 | 模块负责人 |
| `lab_ex5_i2s/src/user_source/hdl_source/team/` | 团队新增模块（OSD、转场、音频可视化等） | B、C |

| `rtl/` | 团队 testbench 使用的 RTL 镜像，由 `scripts\sync_rtl.bat` 单向生成，禁止手改 | 脚本 |
| `tb/` | 团队自己编写的 testbench | B 为主 |
| `scripts/` | 图片转换、TF 卡同步、RTL 同步等工具脚本 | C |
| `assets_src/` | 原始素材：图片、音频、字库源文件 | C |
| `assets_out/` | 脚本生成的 BMP/WAV，已被 .gitignore 排除 | - |
| `doc/` | 团队文档、测试记录、报告草稿 | C |

> 说明：此前的空目录 `constr/` 和 `td_project/` 已删除。官方例程内部已有 `src/user_source/constraints_source/` 与 `src/td_project/`，保留两套会让人分不清哪个是真实工程。

## 2. 打开工程

1. 安装安路 TD 与板载 USB 下载器驱动；
2. 用 TD 打开：`lab_ex5_i2s/src/td_project/HDMI1.4b_Transmitter_v1.0.al`；
3. HDMI 线接开发板 `HDMI_B` 接口，显示器接同一根线；
4. TF 卡格式化为 FAT32，放入 640×480、24 位非压缩 BMP 图片。

## 3. 修改代码的标准流程

1. 在 `lab_ex5_i2s/src/user_source/hdl_source/` 下修改或新增 RTL，团队新增模块统一放在 `hdl_source/team/` 子目录；
2. 在 TD 中把新增的 .v 文件加入工程（工程栏右键 → 添加源文件）；
3. 运行 `scripts\sync_rtl.bat`，把工程源码单向同步到仓库根目录 `rtl/`，供团队 testbench 使用；
4. 仿真、综合、布局布线、生成比特流；
5. 上板验证，并记录 `git rev-parse --short HEAD` 的提交哈希；
6. `git add` / `git commit` / `git push`，通过 PR 合并回 main。

## 4. 不要提交的内容

- TD 构建产物：`*_Runs/`、`log/`、`work/`、`*.bit`；
- 综合与布局布线的数据库：`*.qdb`、`*.qpg`、`*.qtl`；
- 仿真输出：`*.wlf`、`*.vcd`、`transcript`；
- 生成的 BMP/WAV：放在 `assets_out/`，已被忽略；
- 个人 IDE 配置与操作系统临时文件。

## 5. 基线说明

- 基线来源：官方 HX4S20C lab_ex5 例程（含 I2S 音频改动）；
- 导入时只保留源码、约束、IP、工程文件与文档，排除了构建产物；
- 首次在 TD 中打开工程时，TD 会自动重建运行目录；
- 导入完成后建议打标签 `v0.0-baseline-lab_ex5`。
