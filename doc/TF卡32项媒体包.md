# TF 卡 32 项媒体包规范

## 目录结构

TF 卡必须为 FAT32，媒体文件放在根目录：

```text
0101.BMP  0201.WAV
0102.BMP  0202.WAV
...
0132.BMP  0232.WAV
```

FAT 扫描器只接受四个数字加固定扩展名的短文件名。旧脚本生成的
`00_filename.bmp` 不会被当前 RTL 索引，必须使用新命名。

## 一一对应关系

| 图片 | 解说 | 字幕槽 |
|---|---|---|
| 0101.BMP | 0201.WAV | 1 |
| 0102.BMP | 0202.WAV | 2 |
| ... | ... | ... |
| 0132.BMP | 0232.WAV | 32 |

BMP 的数值 ID 为 101 到 132，WAV 为 201 到 232。两组 ID 不能重复，
否则 FAT 索引会报重复文件。

## 生产流程

1. 将 32 张展品图片按播放顺序命名。
2. 将 32 段讲解音频按相同顺序命名。
3. 运行 `scripts/prepare_tf_media.py`，统一裁剪/缩放图片并归一化音频。
4. 运行 `scripts/check_tf_card_images.py`。
5. 插卡后运行 `scripts/sync_to_sd.py`。
6. 上板后逐项检查画面、字幕、声音和切图重播。

配对依据是排序后的源文件名，不读取图片或音频内容中的展品编号。正式制作时
建议源文件使用 `01.jpg`、`01.wav` 到 `32.jpg`、`32.wav`。

## 常见失败

| 现象 | 原因 |
|---|---|
| 图片不切换、数码管停在失败码 | BMP 命名、尺寸或头部格式不合法 |
| 图片正常但无声 | 对应 WAV 缺失、命名错误、时长超限或不是 8 kHz 单声道 s16 |
| 声音与图片错一位 | 源图片和源音频排序顺序不同 |
| 只识别部分文件 | 根目录中的有效名称总数超过 64 |
| 切图后从上一段音频继续 | 应检查 `audio_track_toggle` 与 WAV 加载完成状态 |
