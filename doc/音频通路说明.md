# 音频通路说明（角色 C）

## 1. 当前架构

当前版本已从“4 段片内 8-bit ROM”升级为“32 项 TF 卡 WAV 解说”：

```text
TF FAT32
  0101.BMP..0132.BMP  -> BMP 解析/缩放 -> 帧缓存
  0201.WAV..0232.WAV  -> WAV 校验 -> audio_track_ram
                                      |
                              audio_pcm_player
                                      |
                          64 bit I2S -> I2S_receiver
                                      |
                           ACR_N=6144 -> HDMI 音频包
```

每次选中第 N 张 BMP 后，控制器先完成该帧写入，再按
`0200 + N` 查找对应 WAV。WAV 加载完成后，图像提交脉冲、音频长度、使能
和换轨 toggle 同批更新，避免画面已经切换但声音仍是上一件展品。

如果对应 WAV 不存在或格式错误，图像仍正常提交，音频自动关闭。该行为保证
单个坏音频文件不会阻塞整个轮播。

## 2. 文件契约

### BMP

- 文件名：`0101.BMP` 到 `0132.BMP`
- 分辨率：640×480
- 格式：24-bit RGB、非压缩 `BI_RGB`
- 文件位于 FAT32 根目录

### WAV

- 文件名：`0201.WAV` 到 `0232.WAV`
- 容器：规范 44 字节头 PCM WAV
- 编码：signed 16-bit little-endian
- 声道：单声道
- 采样率：8 kHz
- 最大长度：24576 个样点，即 3.072 秒
- 文件位于 FAT32 根目录

音频在片内 RAM 中循环播放，直到图片切换。播放器用分数累加器把 8 kHz
样本映射到 48 kHz I2S 帧率；I2S 每声道仍为 64 bit，BCLK=MCLK/2，
LRCK=48 kHz。

## 3. 跨时钟域

| 信号 | 方向 | 跨域方式 |
|---|---|---|
| `audio_ram_we/addr/data` | 100 MHz SD 域到双口 RAM 写口 | 写入在提交和 toggle 前完成 |
| `audio_pcm_addr/data` | 音频时钟读口 | 双时钟 BRAM |
| `audio_track_len/ready/enabled` | SD 域到音频域 | 两级同步 |
| `audio_track_toggle` | SD 域到音频域 | 三级同步后取边沿 |
| `I2S_BCLK/LRCK/DOUT` | 音频域到视频域 | 原 `I2S_receiver` 同步链 |

`audio_mclk` 与其余时钟保持异步时钟组约束，不假设固定相位。

## 4. 切换与防爆音

- 新旧音频切换前先执行 20 ms 淡出。
- 淡出结束后清零样点地址和分数采样累加器。
- 再执行 20 ms 淡入。
- 图像缩放重新加载同一张图时，不重复覆盖正在播放的 WAV RAM。

## 5. 资源与存储

`audio_track_ram` 为 24576×16，共 393216 bit，映射为 12 个 32Kb BRAM。
只保留当前解说，不把所有 32 段同时放进片内存储。

TD 原语 `EG_LOGIC_BRAM` 在关闭字节分组时仍要求写口 `bea` 高有效；
`wea=1、bea=0` 会丢弃写入。当前实现固定 `bea=1`，上板无声问题已据此修复。

当前综合规模在 EG4S20BG256 上接近上限，已通过一次种子 2 的完整布线：

- Setup WNS：+0.101 ns
- Setup TNS：0
- Hold WNS：+0.004 ns
- Hold TNS：0
- 9Kb BRAM：61/64
- 32Kb BRAM：12/16
- DSP：14/29

## 6. 生成素材

正式素材：

```powershell
python scripts\prepare_tf_media.py `
  .\assets_src\images .\assets_src\audio `
  -o .\assets_out\tf_card

python scripts\check_tf_card_images.py .\assets_out\tf_card
python scripts\sync_to_sd.py E: -s .\assets_out\tf_card
```

没有正式素材时，可生成 32 张编号图和 32 段不同音高的烟雾测试音频：

```powershell
python scripts\gen_tf_media_smoke.py -o .\assets_out\tf_card
python scripts\check_tf_card_images.py .\assets_out\tf_card
```

`prepare_tf_media.py` 默认拒绝超过 3.072 秒的讲解，避免静默截断丢字。
只有明确接受内容损失时才使用 `--truncate`。

## 7. 字幕

字幕数据源为：

```text
lab_ex5_i2s/osd_assets/captions_test.json
```

生成器支持 1 到 32 项，缺少的项会补占位文案。正式展品信息填入后运行：

```powershell
python lab_ex5_i2s\tools\generate_osd_resources.py
```

生成的 `osd_resources.v` 中保存 32×128 字节字幕槽，标题最多 16 个字符，
简介最多 64 个字符。
